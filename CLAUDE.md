# AvEng — правила проекта

Тренажёр авиационного английского и радиофразеологии для диспетчеров УВД, пилотов,
бортпроводников и сотрудников аэропорта (ICAO Doc 4444, Doc 9432, Annex 1).
Офлайн-PWA и Telegram Mini App. Vanilla JS, без фреймворков и без сборки, GitHub Pages.

Сайт: https://bsheraliev.github.io/atc-english/ · репозиторий `bsheraliev/atc-english` ·
бот `@AvEngApp_bot` · локальная папка `ATC-English-Game` (имя папки и репозитория не совпадают).

Устройство приложения, протокол бэкенда, режимы и механики — в `ИНФО-проект.md`.
Что сделано и что открыто — в `docs/STATE.md`.

## Порядок работы

- **Сначала записать, потом делать.** Слова владельца — первым действием в Issue этого
  репозитория (`gh issue create`), дословно, с датой; только потом браться за работу.
  В докладе называть номер обращения.
- Правки — в ветке `claude/…`, затем запрос на слияние. В `main` сливает владелец:
  слияние и есть выкатка на сайт (GitHub Pages обновляются за ~минуту).
- При любой правке `index.html`, `app.js`, `i18n.js`, `license.js`, `data.js`
  поднимать `APP_VERSION` в `app.js` и `CACHE` в `sw.js` — вместе, одним шагом.
- `docs/STATE.md` обновлять тем же коммитом, что и саму правку.
- Превью: `python -m http.server 8099` из корня репозитория, открывать http://localhost:8099/.
  На машине владельца — `.preview-server.ps1` (порт 8099), в репозиторий он не входит.
- **Проводник:** исходник `docs/guide.html` (он же страница на claude.ai). Копия для сайта
  `guide.html` собирается `python scripts/build-guide.py` — запускать после правки исходника
  **и после каждой смены версии**. `guide.html` вручную не править. Изменились экраны
  приложения — обновить мини-экраны в проводнике.

## Чего в репозитории нет

`data.src.js` (мастер 227 вопросов, диалогов, аудирования и ELPET) и `.aveng-fullkey`
(ключ AES полной базы) — в `.gitignore` и лежат только на машине владельца.

Значит **из облачной сессии контент не правится**: `node build.mjs` без них не соберёт
ни `data.js`, ни `data.full.enc`. Просьбы «добавить вопрос», «исправить формулировку
ответа», «поменять темы в демо» — это работа для локальной сессии; в запрос на слияние
их не брать, а записать обращением и сказать владельцу.

Из облака правятся: `app.js`, `index.html`, `i18n.js`, `license.js`, `sw.js`,
`manifest.webmanifest`, иконки, `backend/*.gs`, документация.

## Ворота — прогнать до слова «готово» и до запроса на слияние

1. Синтаксис всех файлов:

       node --check app.js && node --check sw.js && node --check i18n.js \
         && node --check license.js && node --check data.js && node --check build.mjs

2. Сквозная проверка экранов в превью — все четыре роли, три языка, демо и полный доступ:

       await (await fetch('scripts/smoke.js', {cache:'no-store'})).text().then(eval);
       const r = await AVENG_SMOKE(); r.failed + ' — ' + r.report

   Должно быть `0 — все шаги пройдены`. Упало — не «готово».
   Новый экран или режим — добавить шаг в `scripts/smoke.js`.

Проверка сохраняет прогресс в `localStorage` до запуска и возвращает его в конце,
поэтому её можно гонять и на устройстве с настоящим прогрессом.

## Грабли

- **Service worker врёт при локальной проверке.** Стратегия stale-while-revalidate:
  правка доезжает со второго запуска. Перед проверкой снять регистрацию SW и выполнить
  `caches.keys().then(k => k.forEach(n => caches.delete(n)))`, иначе будешь чинить
  несуществующий баг.
- **Не называть переменные и параметры `t`.** `t()` — функция перевода из `i18n.js`;
  локальная `t` её перекрывает, и экран падает с `t is not a function`.
- **Новая строка интерфейса — сразу в `i18n.js`**, в оба словаря (`tg` и `en`).
  Ключ — русская строка целиком. Без этого язык молча откатывается на русский.
- Значения, вычисляемые при загрузке файла (константы верхнего уровня), через `t()`
  не пропускать: язык ещё не выбран.
- **Проверять и демо, и полный доступ.** В демо `AvEngLic.locked(go)` уводит платные
  режимы на экран кода организации; правка меню, видимая под лицензией, в демо может
  не показаться вовсе.
- **Никогда не коммитить:** `data.src.js`, `.aveng-fullkey`, токены ботов, ключи
  Groq/Gemini, `ADMIN_TOKEN`. Всё уже перечислено в `.gitignore` — не ослаблять.
  Секреты живут в свойствах скрипта Apps Script, их вводит владелец.
- В Telegram недоступен `speechSynthesis` — озвучка идёт файлами из `audio/`,
  а распознавание речи (`pron`) не работает в Telegram на iPhone и в Safari.
- **Проводник открывается слоем, а не переходом на страницу.** Слой лежит в `index.html`
  вне `#app` (экраны перерисовываются через `app.innerHTML` и стёрли бы его), а рамка
  переходит только через `location.replace`: обычный переход кладёт запись в общую историю,
  и тогда «назад» на телефоне листает проводник вместо того, чтобы закрыть слой.

# AvEng — состояние

Обновлено 2026-10-26 (главный экран и вкладки по образцу приложения аэропорта — обращение №16) · версия приложения `1.3.0` · кэш `atc-eng-v23` · банк 227 вопросов (66 в демо).

## Сделано

- **21 режим** в четырёх ролях (диспетчер · пилот · бортпроводник · сотрудник аэропорта),
  все открыты (`WIP_AFTER = 99`): радиоалфавит, 12 тем квиза, аудирование, произношение,
  радиообмен, живой эфир, ELPET/TEA, аттестация, экзамен на время, работа над ошибками.
- **Открытые вопросы** (12 из 227): развёрнутый ответ по-английски → оценка 0–100
  на общем бэкенде (Groq `gpt-oss-120b`, резерв Gemini); без сети — проверка по эталону.
- **Аттестация с проктором:** ФИО, телефон или Telegram (обращение №8), подразделение и организация → код допуска экзаменатору
  (в запросе и результате экзаменатор видит строку «Связь»; в таблице — столбец N; в справку телефон не попадает)
  в Telegram → 20 вопросов, 15 минут, 45 с на вопрос, проходной 75 % → справка и автоотчёт
  в общую таблицу результатов. Антисписывание: счётчик уходов из вкладки, блок копирования.
- **Защита контента:** публичный `data.js` — только пробник; полная база лежит открыто
  в `data.full.enc` под AES-256-GCM, ключ выдаёт Apps Script по коду организации,
  расшифровку делает `license.js`, результат кэшируется и работает офлайн до даты окончания.
- **Три языка интерфейса** (ru/tg/en), словари покрывают все строки экранов.
- **Прогресс и соревнование:** XP, ранги, ачивки, дневная цель и стрик, лидерборд
  (игроки и команды), сертификат о прохождении, вызов коллеги ссылкой.
- **Аналитика** GoatCounter (код `aveng`) с меткой платформы `tg` / `web`.
- **Проводник «Как заниматься»** (обращение №5): пошаговая инструкция с мини-экранами
  приложения, две дорожки — «Я занимаюсь» (10 шагов) и «Я сдаю аттестацию» (8 шагов).
  Исходник `docs/guide.html`, копия для сайта `guide.html`. Открывается из приложения
  слоем поверх экрана — с главного экрана, с экрана кода организации и с экрана аттестации;
  введённые данные при этом не теряются. Лежит в офлайн-кэше. **В эфире с 2026-10-13**,
  проверен на боевом сайте: https://bsheraliev.github.io/atc-english/guide.html
  С 1.2.4 скрипт проводника целиком внутри функции и не оставляет имён в окне: в Telegram
  для iPhone чужой скрипт перезаписывает общие имена (`head`, `body`…) — так 15.10.2026 упал
  портал Shohin. Функция мини-экрана `body` переименована в `abBody`.
- **Порядок работы под облачные сессии** (обращение №3, слито): правила в `CLAUDE.md`,
  состояние здесь, сквозная проверка экранов в `scripts/smoke.js`, очередь — Issues.
- **Защита от «пустого экрана» на iPhone** (обращение №12, 1.2.5): при ошибке нашего кода внизу
  экрана панель с текстом ошибки, версией, платформой Telegram и списком функций, подменённых
  чужим скриптом (`__avengDiag`, по образцу портала Shohin); кнопки «Скопировать / Перезапустить /
  Закрыть». Переводчик `t` — `const` (его не подменить через `window.t`). Если облако Telegram
  не ответило за 2 с, меню открывается без него (раньше экран оставался пустым). `icon-180.png`
  добавлена в офлайн-кэш.
- **Кнопка «Связаться в Telegram» без t.me** (обращение №14, 1.2.6): у части провайдеров t.me
  не резолвится (`DNS_PROBE_FINISHED_NXDOMAIN`). Ссылки с `data-tg` внутри Telegram открываются
  через `openTelegramLink`, в браузере — сразу приложение по `tg://resolve?domain=Ori_gemini_bot`;
  не открылось за 1,5 с — окно с ником `@Ori_gemini_bot` и «Скопировать» (t.me — лишь запасная ссылка).
- **Главный экран и вкладки по образцу приложения Brussels Airport** (обращение №16, 1.3.0):
  нижняя панель «Главная · Разделы · Аттестация · Прогресс · Ещё» (только на экранах-вкладках;
  внутренние экраны — с «‹ Меню», без панели). Главная: синяя шапка-приветствие, переключатель
  ролей, поиск (разделы + «Тренировка по запросу» по вопросам со словом), ряд круглых ярлыков,
  карточки «Вам понравится…» с метками (Игра/Вызов/Экзамен/Гид), «Вопрос дня» (один на день
  для роли) и карточка отзыва (открывает форму `feedback.js`). «Разделы» — фильтры-«пилюли»
  (поле `grp` в `MENU`) и крупные карточки. «Прогресс» и «Ещё» — сгруппированные списки
  со стрелками; язык меняется прямо в «Ещё». Сквозная проверка дополнена (84 шага).
- **Кнопка «Сообщить об ошибке»** (`feedback.js`): обращения пользователей идут в закрытую очередь.

## Открыто

- **Проводник: мини-экраны главного устарели** после 1.3.0 (обращение №16) — обновить, когда
  владелец утвердит новый главный экран. Затем — перенос того же вида в AvSec и СУБП.

| Что | Где |
|---|---|
| Webhook ботов не включён — подписчики не считаются | `backend/SETUP-подписчики.md`, шаги 3–4 |
| Ежедневные напоминания выключены (`REMINDERS.on = false`) | `app.js` + `backend/reminders.gs` |
| Ролевые треки «бортпроводник» и «аэропорт» тоньше по контенту остальных | `data.src.js` (только локально) |
| Номера строк в таблице «Ручки в коде» устарели после правок 1.2.x | `ИНФО-проект.md` |
| AvSec ушёл вперёд по движку (1.5.0): модуль разбора, аудитории и роли — перенести к AvEng | репозиторий `bsheraliev/avsec` |

## Ждёт владельца

- **Токены ботов и webhook** — секреты вводит владелец (`BOT_TOKEN_AVENG` в свойствах скрипта).
- **Правка вопросов** — только на машине владельца: мастер `data.src.js` и ключ AES
  в репозиторий не входят.

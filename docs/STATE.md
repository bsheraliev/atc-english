# AvEng — состояние

Обновлено 2026-10-13 · версия приложения `1.2.1` · кэш `atc-eng-v15` · банк 227 вопросов (66 в демо).

## Сделано

- **21 режим** в четырёх ролях (диспетчер · пилот · бортпроводник · сотрудник аэропорта),
  все открыты (`WIP_AFTER = 99`): радиоалфавит, 12 тем квиза, аудирование, произношение,
  радиообмен, живой эфир, ELPET/TEA, аттестация, экзамен на время, работа над ошибками.
- **Открытые вопросы** (12 из 227): развёрнутый ответ по-английски → оценка 0–100
  на общем бэкенде (Groq `gpt-oss-120b`, резерв Gemini); без сети — проверка по эталону.
- **Аттестация с проктором:** ФИО, подразделение и организация → код допуска экзаменатору
  в Telegram → 20 вопросов, 15 минут, 45 с на вопрос, проходной 75 % → справка и автоотчёт
  в общую таблицу результатов. Антисписывание: счётчик уходов из вкладки, блок копирования.
- **Защита контента:** публичный `data.js` — только пробник; полная база лежит открыто
  в `data.full.enc` под AES-256-GCM, ключ выдаёт Apps Script по коду организации,
  расшифровку делает `license.js`, результат кэшируется и работает офлайн до даты окончания.
- **Три языка интерфейса** (ru/tg/en), словари покрывают все строки экранов.
- **Прогресс и соревнование:** XP, ранги, ачивки, дневная цель и стрик, лидерборд
  (игроки и команды), сертификат о прохождении, вызов коллеги ссылкой.
- **Аналитика** GoatCounter (код `aveng`) с меткой платформы `tg` / `web`.
- **Порядок работы под облачные сессии** (это обращение №3): правила в `CLAUDE.md`,
  состояние здесь, сквозная проверка экранов в `scripts/smoke.js`, очередь — Issues.
